大富翁 Deal

通过出牌、收租和交易凑齐地产组。支持本地对局、机器人和同一局域网内的多人对局。

  • Java 17
  • JavaFX
  • TCP
  • JUnit
查看技术细节

玩家端提交操作，主机使用规则引擎校验后同步每位玩家可见的牌局状态。同一套规则处理回合、行动牌和付款流程。项目中包含规则和主机／客户端联机的测试代码。

课程项目 · 街机游戏

青蛙过河

在倒计时内躲过车流，借助浮木和乌龟越过河道，抵达对岸。关卡推进后，障碍移动得更快。

  • Java
  • JavaFX Canvas
  • 课程引擎
查看技术细节

每次更新处理按键、计时和障碍移动，再根据碰撞及平台接触状态更新青蛙。站上移动平台时，青蛙会随平台一起移动。
